PFI protocol

Original test log loss: 0.4090. Each input is separately shuffled 50 times across all evaluation rows, seed 42. Every repeat copies the original matrix. The predictor and outcomes stay fixed.

The difference is permuted log loss minus original log loss. The ratio divides permuted log loss by original log loss. Log loss uses the natural logarithm and is nonnegative, with no finite upper bound. Whiskers show one sample standard deviation across shuffles (ddof = 1), conditional on this fitted model and these evaluation records.

The historical full-test dependent-input diagnostics reuse the same fitted model and full-test baseline. Joint shuffling moves heart disease and diabetes using the same donor row. Subgroup shuffling moves heart disease only within each diabetes category. Neither resolves all other input dependencies.

Generic reproduction algorithm

The browser replays measured predictions and aggregate results; it does not execute XGBoost. The evidence notebook runs the algorithm below on the full temporal test. The teaching window displays receivers from its first registered repetition, while the chart reads the recorded global comparison.

from sklearn.metrics import log_loss

# Inputs: a fitted probability predictor and evaluation data with outcomes.
rng = np.random.default_rng(42)
orders = [rng.permutation(len(x_eval)) for _ in range(50)]
p_original = np.asarray(model.predict_proba(x_eval)[:, 1], dtype=np.float64)
e_original = log_loss(y_eval, p_original, labels=[0, 1])
for feature in x_eval.columns:
    errors = []
    for order in orders:
        x_perm = x_eval.copy()
        x_perm[feature] = x_eval[feature].iloc[order].set_axis(x_eval.index)
        p_perm = np.asarray(model.predict_proba(x_perm)[:, 1], dtype=np.float64)
        errors.append(log_loss(y_eval, p_perm, labels=[0, 1]))
    delta = np.asarray(errors) - e_original
    importance = delta.mean()
    shuffle_sd = delta.std(ddof=1)
