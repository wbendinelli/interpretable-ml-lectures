# Interactive PFI lesson

This is the canonical browser presentation for [module 06](../../README.md).
Its opening context map follows selected interpretation categories from
Molnar’s methods overview; his Permutation Feature Importance chapter guides
the method and interpretation. Raschka inspires the visual sequence of the
following examples. Its empirical results come from
the recorded SRAG experiment. The column animation shows fixed real receivers within the first recorded
full-test permutation. Its error chart, ranking and repeat trace use the
complete temporal test.

## Run the lesson

From the repository root:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Open the lesson at
`http://127.0.0.1:8765/modules/06-pfi/lecture/pfi-interactive/index.html`.
An HTTP server is required because the lesson fetches JSON and SVG assets;
opening the HTML directly from the filesystem is unsupported. A GitHub source
page displays the code, rather than running this presentation.

The repository version reuses [the course fonts](../../../../tools/fonts/README.md)
instead of keeping another copy. Serve the repository root so those relative
font paths resolve. The recorded teaching data, dataset-level results and
figures required by the runtime are bundled within this directory. No trained
model or raw dataset is required to display the lecture.

The display code is split by responsibility: `lecture.js` owns navigation and
the context map; `pfi-example.js` owns the real-record shuffle and ranking;
`sequence.js` owns the code walkthrough and recorded repeat trace;
`study.js` owns study slides and diagnostics. The compact slide definitions
keep study and interpretation text separate from their animation controllers.
`presentation-grid.css` governs the common layout after component styles;
`navigation.css` refines the compact navigation at the lower right;
`real-records.css` styles the teaching rows and their recorded predictions.

The browser replays measured predictions; it does not execute XGBoost.
Each column starts from the original full evaluation matrix. The table shows
fixed receivers, whose donor values come from the first registered permutation
across the entire temporal test. Donors can be outside the visible rows.
The adjacent chart uses the original global log loss and the mean and shuffle SD
across the registered repetitions; the displayed first repetition is identified
separately. It does not use the loss of the visible receivers.

The receivers are the first adult records per observed outcome, then original
dataset order. Selection is independent of predictions and correctness; it is
not a performance sample. Age is in decimal years. Received values belong to
real evaluation inputs, but a permuted record is an artificial combination:
the recipient’s other inputs and observed outcome stay fixed. Repeated
categories can leave a probability unchanged.

The manual teaching shuffle remains in the module 00 historical record.
Its arithmetic was reproducible, but its fixed order happened to retain
outcome blocks within the selected rows. The current window uses the actual
global repetition and preserves the original receiver data and predictions.

## Check or export the static presentation

[The content exporter](../../../../tools/srag_72_pfi_presentation.py) uses an
explicit, typed field allowlist at every level. It projects the scientific
global record in module 00 and the teaching evidence in module 06 into
separate files, verifies the canonical data and checks static resources:

```sh
python tools/srag_72_pfi_presentation.py --check
```

To prepare an independent static folder, choose an absent or empty temporary
directory outside the repository:

```sh
python tools/srag_72_pfi_presentation.py --output-dir /tmp/pfi-static-export
python -m http.server 8766 --bind 127.0.0.1 --directory /tmp/pfi-static-export
```

The exported folder has local copies of the used fonts and their OFL notice.
Only declared runtime assets and the two selected data files are copied.
The teaching file includes original receiver inputs and outcomes,
individual predictions/errors, received values and the global repeat protocol.
It excludes source identifiers, dates, location fields, donor positions and
donor outcomes; omission of identifiers does not establish anonymization.
No notebooks, raw datasets, research directories, association cross-tabs,
subgroup tables, snapshots or original slide images are exported. Exporting
prepares a reviewable folder; it does not publish it or configure hosting.

Both data files are generated from scientific evidence. The aggregate JSON
remains free of individual records. The teaching evidence is generated by
[srag_73_teaching_demo](../../../../tools/srag_73_teaching_demo.py), which
reproduces the registered global orders before predicting with the fixed model.
`project_teaching_records` and `validate_teaching_records` check its explicit
projection; the exporter also checks the first global errors against the
original PFI record. The notebooks print the global comparison and separately
audit receiver losses.
Current figure copies are generated by the module 06 log-loss walkthrough
from the recorded global scores and recomputed dependence diagnostics. Promote regenerated figures explicitly and document
their generating cell, following the repository’s contribution policy.
