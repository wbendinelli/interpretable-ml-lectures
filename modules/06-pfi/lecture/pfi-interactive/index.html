Reading the error

A probability can be more or less wrong.

First read the observed outcome: 0 = survived; 1 = died. Then measure how far the predicted probability is from that outcome. Square that distance, and average across records.

The example uses one teaching row. The demo error averages eight rows; the ranking uses the full test. Brier measures probability error; it is not a pure calibration statistic. Displayed values are rounded; calculations retain full precision.
